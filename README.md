# 67 Hero — Move Test

Empty test map for the 67 hero character. Movement and effects only.

- Sprint: shield bubble, white energy trail, screen speed lines, FOV push
- Jump, drift-jump hover with burst
- Hard landing: white shard burst and shockwaves
- Power burst: green energy explosion, rising spiral glow, camera shake
- Spawn bubble

Desktop: WASD, drag to look, Shift sprint, Space jump / hover, E power, R respawn.
Mobile: virtual stick, JUMP / SPRINT / POWER buttons.
